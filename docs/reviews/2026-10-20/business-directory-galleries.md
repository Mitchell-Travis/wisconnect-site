# Official business directory galleries

Added three official website photos to the expanded detail views for Momentum Coffee and BDavis Designs. The directory cards keep their existing brand presentation; gallery images are requested only when a visitor opens a business.

## Momentum Coffee

The gallery uses the site's own image CDN with 640px and 960px responsive sizes and automatic modern image format selection. Images are lazy-loaded and decoded asynchronously.

- [Momentum Coffee website](https://momentumcoffee.org/)

## BDavis Designs

The gallery uses three photos from the official [BDavis Designs website](https://www.bdavis-designs.com/). Each was converted to local WebP at 640px and 1200px wide, stripping source metadata and retaining responsive source selection. The six files total about 323 KiB.

- [Homepage photo 3](https://www.bdavis-designs.com/2025/wp-content/uploads/2026/01/HomepageGraphic3.jpg)
- [Homepage photo 2](https://www.bdavis-designs.com/2025/wp-content/uploads/2026/01/HomepageGraphic2.jpg)
- [Homepage photo 1](https://www.bdavis-designs.com/2025/wp-content/uploads/2026/01/HomepageGraphic1.jpg)

Both listings now link to their official websites in the detail panel. Static catalog values and migration `0013_official_business_websites` keep GitHub Pages and database-backed directories in sync. Images use accurate alt text, fixed intrinsic dimensions and lazy loading.

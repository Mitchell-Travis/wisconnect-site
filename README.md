# WisConnect landing page — first build

This project is the first responsive front-end pass for the WisConnect public landing page.

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## What is included

- Responsive desktop, tablet and mobile layouts
- Sticky navigation and mobile menu
- Real WisConnect logo, portrait and background assets supplied by the project
- Hero, manifesto, cooperative model, members, businesses, programs, impact, global reach, stories, CTA and footer
- Interactive member-business sector filters
- Interactive global-region storytelling
- Phase-aware information architecture: public Phase 1 now; marketplace/member portal reserved for Phase 2

## Content status

This build deliberately does not invent public member profiles or impact metrics. Those areas are visibly structured but need verified/consented WisConnect data before production launch.
